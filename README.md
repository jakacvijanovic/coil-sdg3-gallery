# Fieldnotes on Health

An English-language COIL gallery exploring SDG 3 through movement, green space and access to care. Open index.html or use GitHub Pages. The responsive page includes three illustrated stories, a three-question quiz with feedback and a link to the UN targets. The photographs are served by Unsplash and require an internet connection.

## Student contributions

The initial website was prepared with Codex. Before school submission, each partner should add six original photographs, a presentation video and a short account of their own work. Work on separate branches and review each other's pull requests.
